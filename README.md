# Exploratory Data Analysis Project Using Python
The purpose of this project is to master exploratory data analysis (EDA) in with Pandas framework.

## Goals of the Project
- Explore a dataset with Pandas framework.
- Visualize the dataset with various plot types.

## Data Sources
The primary dataset used for this analysis is the "Global YouTube Statistics.csv" file. It contains global youtube statistics data, including 995 rows and 28 colums of data with features on subscriber count, channel type, category, and others.
